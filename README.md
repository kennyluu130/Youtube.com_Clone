# YouTube Clone 📺

A **frontend clone of YouTube** built using **HTML and CSS**.  
This project demonstrates a responsive web design that mimics the look and feel of the YouTube platform.

---

## 🌟 Features
- Responsive web design for desktop and mobile devices.
- Mimics YouTube’s layout, including video thumbnails, navigation, and search bar.
- Clean and modern UI built with HTML and CSS only.

---

## 🛠 Technologies
- HTML5
- CSS3
- Responsive Design (Flexbox / Grid)

---

## 📄 Installation / Usage

1. **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/Youtube.com_Clone.git
    ```

2. **Open `index.html`** in your browser to view the application locally.
